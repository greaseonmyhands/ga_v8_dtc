About this file — scope, sources, and what to watch out for

What this is

One searchable list of every engine and transmission DTC found in GM's public OBD certification documents (the "OBDG" Engine / Transmission / Diagnostics PDFs from the GM OBD portal) that applies to 5.3 L (L83/L8B) and 6.2 L (L86) K2XX-era Silverado/Sierra/SUV hardware, plus the C7 Corvette, 6th-gen Camaro and CTS-V sections in the same filings. Each code carries everything the PDF table has for it: component, monitor strategy description, malfunction criteria, threshold, secondary parameters, enable conditions, time required and MIL illumination. A DTC that applies to some hardware and not others is kept once, with its variants listed under it.

Caveats

Applicability is by document section, not per vehicle. GM files one document per OBD group and bundles every engine/transmission calibration for the model year into it. "Common" sections apply to every vehicle in the group; "Unique" sections apply only to the named engine or transmission. This list drops the sections for other engines (V6, 4-cylinder, diesel, hybrid, HD 6.0 L, vans) but a code from a "Common" section may still be inactive on a specific calibration. The vehicle chips show which of your platforms the source section belongs to.
Extraction quality. Text was rebuilt from the positioned words in the PDFs using the table's own ruled grid. Cells keep their line breaks, so multi-column fragments (parameter name | value | unit) read in row order but can look fragmented. Where the PDF has a value in a supporting table (a calibration name such as KtFHPD_…), the table value is not in these documents. 2020's ECM tables are not text in the PDF (they are drawn as vector shapes), so 2020 contributes only its transmission section and a few ECM rows. The 2019 combined file is not split between engine and transmission calibrations beyond its section labels.
Same code, different numbers by year. Thresholds change between model years (for example the SIDI high-pressure pump windup limits). Use the variant cards to see each year's values.
